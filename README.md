A make.fun entry for [Fortune in a Pot](https://make.fun/c/u-golden-heron-44-fortune-in-a-pot-ded981e9): one kind, funny fortune for the houseplant on the windowsill, in 120 characters or fewer.

`main.py` writes the fortune to `/output/entry.txt`:

> A sunny week is coming: you will stretch toward the glass, sprout a proud new leaf, and be photographed far too often.

Run it with `python3 main.py`.
